# B站分P观看进度（Edge 扩展）

在 B 站分 P 视频页面显示你的观看进度占总时长的比例，以悬浮窗形式展示，随分 P 切换和播放实时更新。

## 功能

- 在视频页面右侧显示悬浮窗：`百分比 · P3/12 · 已看 35:20 / 2:10:05`
- 粉色进度条实时反映观看比例
- 切换分 P 时自动更新（B 站为单页应用，无需刷新页面）
- 当前 P 之前的所有分 P 按完整时长计入已看时长
- 点击扩展图标可随时开关悬浮窗

## 安装

1. 克隆或下载本仓库
2. 打开 Edge，地址栏输入 `edge://extensions`
3. 打开左下角**开发人员模式**
4. 点击**加载解压缩的扩展**，选择本仓库文件夹
5. 打开任意 B 站分 P 视频页面（`bilibili.com/video/BVxxxx?p=n`）即可看到悬浮窗

## 工作原理

- 从页面 URL 解析 BV 号与当前分 P（`p` 参数）
- 调用 B 站网页端接口 `x/web-interface/view` 获取全部分 P 的时长
- 读取页面 `<video>` 元素的 `currentTime` 获取实时播放位置
- `已看比例 = （之前所有分 P 时长之和 + 当前播放位置） ÷ 总时长`

扩展只申请 `storage` 权限（用于保存开关状态），所有数据均在本地处理，不发送至任何第三方。
